# Code and data

[MIT](LICENSE) applies to the author's code. It does not relicense third-party
data or grant permission beyond each source's terms.

- Station data: U.S. DOE Alternative Fuels Data Center, via the NREL API.
  [API documentation](https://developer.nrel.gov/docs/transportation/alt-fuel-stations-v1/).
  This product uses the NREL API but is not endorsed or certified by NREL.
- Demographics and boundaries: U.S. Census Bureau, ACS 2019–2023 five-year
  estimates and TIGER/Line 2024. [Census data](https://www.census.gov/data.html).
- Environmental-justice proxy: CalEnviroScreen 4.0, OEHHA and CalEPA.
  [Source release](https://oehha.ca.gov/calenviroscreen/report/calenviroscreen-40).
  Crosswalked percentiles are project estimates, not OEHHA-published values or
  official regulatory designations.

Raw downloads remain local. The two committed processed CSVs preserve the
published analysis inputs; their inclusion is not a blanket license for source
datasets. Preserve attribution when redistributing derived results.
